# Mazen Hisham — Portfolio

A modern portfolio built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.

🌐 **Live site:** https://mazen771.github.io/Mazen-hisham/

---

## 🚀 Deploy to GitHub Pages

### Option A — Automatic (Recommended)
Every push to `main` triggers the GitHub Actions workflow (`.github/workflows/deploy.yml`) which builds and deploys automatically.

### Option B — Manual deploy
```bash
npm install
npm run deploy
```

---

## 🛠 Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080)

---

## 🏗 Tech Stack

- React 18 + TypeScript
- Vite 5

- shadcn/ui
