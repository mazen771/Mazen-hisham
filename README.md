# Mazen Hisham — Data Scientist Portfolio

A modern, dark-themed personal portfolio showcasing my work in data science, machine learning, data analysis, and visualization.

**Live site:** https://mazenhisham.lovable.app

## About

I'm Mazen Hisham, a Data Scientist focused on turning raw data into actionable insights through statistical analysis, machine learning, and clean, interactive interfaces. This portfolio highlights selected projects, skills, and ways to get in touch.

## Tech Stack

- **Vite** — build tooling
- **React 18** + **TypeScript**
- **Tailwind CSS** + **shadcn/ui** components
- **Lucide React** icons
- **React Router**

## Features

- Glassmorphism dark UI with gradient/neon accents
- Project gallery with category filtering
- Skills, experience, and about sections
- Contact via `mailto:` (no backend required)
- Fully responsive

## Getting Started

Requires Node.js (v18+) and npm.

```sh
# Clone the repository
git clone https://github.com/MazenHisham1/<repo-name>.git
cd <repo-name>

# Install dependencies
npm install

# Start the dev server
npm run dev
```

The app will be available at `http://localhost:8080`.

## Build

```sh
npm run build
```

Production output is generated in `dist/`.
